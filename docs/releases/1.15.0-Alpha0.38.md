# 1.15.0+Alpha0.38

## 会议地图标记

- 会前位置使用红色像素定位针，针尖对应原始坐标，上方显示多语言“会前位置”。
- 被报告尸体使用浅灰骷髅、深红眼眶和红色下划线；均为透明轮廓，无黑色矩形底板。
- 会前位置与尸体位置的平面距离不超过 6 格时，只显示会前位置；不受两者高度差影响。没有有效会前标记时，尸体标记保留。
- 小地图和展开地图复用同一套绘制数据，会议标记绘制在任务、房间文字上方；不新增实体或材质依赖。

## 统一洞穴检测

- 锁定的小地图、展开地图自动洞穴检测配置均从 2 改成 1，即原生 3×3 改为 1×1，连接 GooseTools 后对所有玩家一致生效。
- 保留当前地图洞穴可用性、强制地表地图、会议前位置及会议地图层保留规则。离开 GooseTools 服务器后仍使用玩家原有本地配置。
- 原生实现范围为 1 + 2*(配置值 - 1)，因此值 1 对应头顶所在的单列。

验证：Alpha0.38 test build 通过（4574 项单元测试）；原生 Xaero 客户端回归确认两个配置均被锁为 1；正式地图绘制代码 GPU 截图检查透明图标和近点抑制。未进行多人服务器游玩实测。

本次仅发布代码，不替换游戏文件。本机已安装的测试包仍为 Alpha0.37；联机客户端与服务器应使用相同版本。
