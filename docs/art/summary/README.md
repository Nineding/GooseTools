# Summary sprites

Original pixel atlas generated with ImageGen on 2026-10-13. PerfectPixel (Majority Cluster, OpenCV, export scale 1) detected a 128 × 128 grid. The saved ComfyUI workflow scales RGB and the original inverse-alpha mask separately to 256 × 256 with nearest-exact and rejoins alpha. Runtime atlas: `assets/goosetools/textures/gui/summary/atlas.png`. Four cells: award, goose coin, level badge, sparkle. Text is rendered separately.
