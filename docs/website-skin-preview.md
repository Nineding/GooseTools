# 网页商城的本人皮肤预览

Alpha0.72 增加可选的已加载皮肤同步。它读取客户端当前玩家的真实皮肤纹理，支持由 CustomSkinLoader 加载的皮肤站和本地皮肤，不需要把 CSL 安装到服务端。PNG 仅按已验证连接的 UUID 保存；网页还需用登录账户的已验证绑定 UUID 读取。临时服务器变身标记的外观不作为账号皮肤保存。

在需要接入官网的服务器创建 `config/goosetools/skin-preview.json`：

```json
{"enabled":true,"directory":"../../shared/player-appearance"}
```

路径相对于服务端工作目录。多个子服与私人房模板使用同一受控共享目录；未配置或 `enabled:false` 时不会请求或保存皮肤。网站通过 `GAME_PLAYER_APPEARANCE_PATH` 指向同一目录。无需对该目录开放静态文件访问，网页接口应始终使用账户本人已验证的绑定 UUID。

每个 `<uuid>.json` 是原子替换的单份快照：`schema:1`、`uuid`、`model`（`slim` 或 `default`）、`updatedAt`（服务器毫秒时间戳）、`sha256` 和 `png`（PNG base64）。没有外部 URL、玩家上传路径、皮肤站设置或凭据。皮肤只在服务器请求后采集；玩家进入服务器约五秒后开始，之后每十五秒检查实际像素和模型变化，相同内容不重复上传。同步不涉及购买或装备状态。

网络块不超过 24 KiB，PNG 不超过 512 KiB，尺寸限 64 至 1024 的二次幂标准皮肤。分块按连接隔离，限速、超时、重复块和内容校验通过后才保存，服务端重新解码 PNG 并移除额外元数据。皮肤尚未同步时，网页应提示进服一次，保留原有商品图，不替换为其他玩家或不匹配的官方皮肤。
